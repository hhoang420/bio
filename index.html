Cách đưa lên GitHub Pages để ai bấm vào cũng xem được

  1. Chỉnh sửa giao diện, ảnh nền, nhạc và các link ở các tab bên cạnh cho thật ưng ý (Mọi thay đổi đang được lưu tự động trên trình duyệt của bạn).
  2. Bấm nút "Tải xuống file config.json" bên dưới và lưu đè vào thư mục code của bạn (hoặc copy nội dung JSON dán vào file config.json trên GitHub).
  3. Đẩy bộ file (index.html, style.css, app.js, config.json) lên GitHub Repository của bạn và bật Settings → Pages.
  4. Mẹo: Khi gửi link cho người khác, nút "Tùy chỉnh" có thể ẩn đi hoặc bạn thêm ?edit=1 vào cuối link khi muốn mở bảng cài đặt!
